Compound Interest Calculator (JavaScript)
Objective
To create a JavaScript program that calculates compound interest using
static values, variables, and operators.
Formula
The compound amount is calculated using:

A = P`\left`{=tex}(1 + `\frac{r}{n}`{=tex}`\right`{=tex})\^{nt}

Compound interest:

\(CI = A - P\)

Where:
- A = Final amount
- P = Principal amount
- r = Annual rate of interest (in decimal form)
- n = Number of times interest is compounded per year
- t = Time in years
- CI = Compound interest
